# QuantSpace — Algorithmic Trading Platform

Премиальная платформа алгоритмической торговли с прозрачными результатами и профессиональными инструментами.

## 🎨 UX и анимации

### Система анимаций

Создана полноценная система анимаций для улучшения пользовательского опыта:

#### Компоненты анимаций

- **FadeIn** — плавное появление элементов при скролле с настраиваемым направлением (up/down/left/right)
- **StaggerContainer + StaggerItem** — последовательное появление элементов списка
- **AnimatedCounter** — анимированные счётчики для чисел с easing функциями
- **MagneticButton** — интерактивные кнопки с эффектом магнитного притяжения к курсору
- **Card + GlowCard** — карточки с hover эффектами (scale, translate, shadow, glow)
- **ScrollProgress** — индикатор прогресса скролла страницы
- **Skeleton** — состояния загрузки с shimmer анимацией
- **Toast** — система уведомлений с анимированным появлением/исчезновением

#### Микроинтеракции

- **Hover эффекты** — плавные transitions на всех интерактивных элементах
- **Spring анимации** — физически корректные движения с использованием spring physics
- **Stagger delays** — последовательное появление элементов для создания ритма
- **Scale + Translate** — комбинированные трансформации для глубины
- **Rotate** — вращение иконок при hover для привлечения внимания
- **Glow эффекты** — свечение при наведении на важные элементы

#### Page transitions

- **AnimatePresence** — плавные переходы между состояниями
- **Mode="wait"** — корректная последовательность exit/enter анимаций
- **Duration 0.3s** — оптимальное время для transitions

#### Scroll animations

- **Intersection Observer** — элементы появляются при попадании в viewport
- **Trigger once** — анимация срабатывает только один раз
- **Threshold настройки** — гибкая настройка момента срабатывания

### Улучшения UX

#### Визуальная обратная связь

- **Toast уведомления** — мгновенная обратная связь при действиях пользователя
- **Loading states** — skeleton загрузчики для ожидания данных
- **Hover states** — чёткие визуальные индикаторы интерактивности
- **Focus states** — доступность для клавиатурной навигации

#### Навигация

- **Smooth scroll** — плавная прокрутка к якорям
- **Scroll progress** — индикатор позиции на странице
- **Mobile menu** — анимированное выдвижное меню
- **Active states** — чёткое выделение текущей страницы

#### Формы

- **Animated inputs** — плавные transitions при фокусе
- **Validation feedback** — мгновенная обратная связь при ошибках
- **Password visibility** — переключатель видимости пароля
- **Submit animations** — визуальная обратная связь при отправке

#### Карточки

- **Lift on hover** — подъём карточки при наведении
- **Shadow depth** — увеличение тени для эффекта глубины
- **Border color** — изменение цвета границы при hover
- **Scale transform** — лёгкое увеличение для привлечения внимания

### Производительность

- **GPU acceleration** — использование transform и opacity для анимаций
- **Will-change** — оптимизация для часто анимируемых элементов
- **Reduced motion** — поддержка prefers-reduced-motion для accessibility
- **Lazy loading** — отложенная загрузка тяжёлых компонентов

### Accessibility

- **Keyboard navigation** — полная поддержка клавиатурной навигации
- **Focus visible** — чёткие индикаторы фокуса
- **ARIA labels** — семантическая разметка для screen readers
- **Reduced motion** — отключение анимаций для пользователей с вестибулярными расстройствами

## 🚀 Технологии

- **React 18** — современный UI фреймворк
- **TypeScript** — типизация для надёжности
- **Vite** — быстрая сборка и HMR
- **Tailwind CSS** — utility-first стилизация
- **Framer Motion** — продвинутые анимации
- **Recharts** — профессиональные графики
- **React Router** — клиентская навигация
- **Lucide React** — современные иконки
